# ITRDB validation datasets

The repository records dataset DOIs and SHA-256 values for the six raw Tucson RWL
files used in development validation. The raw files are not duplicated in the
initial GitHub commit. They are acquired from their ITRDB/NCEI dataset records and
verified against `itrdb_dataset_manifest_v01.csv`.

No suggested publication was supplied in the downloaded ITRDB metadata for these
legacy datasets. This statement does not assert that no related publication exists;
it records only the state of the downloaded metadata.
